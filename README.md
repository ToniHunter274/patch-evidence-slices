## Data attribution
This repository contains a task-specific extract of `data/labels/entries.csv` from [Gold-Coupled Tests](https://github.com/ph-phuc/swe-bench-gold-coupling), by Phuc Phan.
Original source commit: `10869825a6b47e70785483083e2828a8ec683155`.
The original derived data is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). This extract selects records for two SWE-bench tasks and adds a source-line column. No benchmark outcomes have been changed.
This is a derived research extract, not an independent benchmark.
